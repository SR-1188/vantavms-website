# VANTA VMS — Marketing Website

Official marketing site for VANTA, a browser-native enterprise Video Management System.

**Live at:** https://vantavms.com

## Structure
- `index.html` — home: hero, live camera grid, AI detection demo, stats
- `features.html` — full capability breakdown
- `industries.html` — industry use cases
- `contact.html` — demo request form
- `css/style.css` — all styles
- `js/main.js` — all interactivity (reticle cursor, walker detection demo, event feed, animations)

## Hosting
Hosted free on GitHub Pages with custom domain vantavms.com.

## Stack
Pure HTML/CSS/JS. Zero frameworks, zero build step, zero dependencies.
